# #コンパス キャラ診断 v6.0（完成版パッケージ）

## 遊び方
ZIPを解凍し、`index.html` を開いてください。`images/` フォルダーは同じ場所に置いてください。

- 51人のオリジナルヒーロー、51枚の画像
- 20問・はい／いいえ方式。前半10問共通、後半10問は回答で変化
- 1位〜3位の結果、回答の振り返り、戻る、再診断
- 糸廻輪廻の追加質問とゲーム内のネタ演出

## 注意点
- 51人に異なる専用回答プロフィールがあることは確認済みですが、実際の質問分岐で全員が1位になること、実ユーザーの結果が均等になることは保証していません。
- キャラの特徴には暫定設定があり、診断の妥当性は未検証です。
- 自動ブラウザ検証はPCとモバイルサイズのChromium。実機iPhone・Androidの検証は未実施です。
- インターネットへの公開は未実施。画像の権利元ガイドラインを確認してから公開してください。

`公開手順.md` に公開方法を記載しています。
